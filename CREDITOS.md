# Créditos

Projeto acadêmico Game Center.

Integrantes: Josh (20251012000210) e Cecília (20251012000856).

Referência de requisitos: APP05 — Pocket Arcade — Central de Desafios, Prof. Fernando Gonçalves Abadia; conteúdos das Aulas 01 a 07 de Desenvolvimento de Aplicações para Dispositivos Móveis.

Ícones genéricos de controle, scanner, arena, cofre, sorteio, pedra, papel e tesoura: vetores produzidos diretamente em XML para este projeto. Não foram usadas imagens externas.

Sons `vitoria.wav`, `derrota.wav` e `sorteio.wav`: sequências curtas de tons sintetizados para este projeto, sem gravações de terceiros.

Textos e opções iniciais: conteúdo genérico elaborado para esta versão funcional. A identidade visual final será aplicada pelos integrantes.
